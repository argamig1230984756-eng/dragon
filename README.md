# DragonBuff (Paper 1.21.11)

Build:   mvn clean package     (needs JDK 21 + Maven)
Install: copy target/DragonBuff-1.0.0.jar into your server's /plugins folder
Config:  plugins/DragonBuff/config.yml   (/dragonbuff reload to reload)

Bedrock: install Geyser + Floodgate on the Paper server. DragonBuff is 100% server-side.
